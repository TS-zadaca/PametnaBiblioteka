# PametnaBiblioteka

Projekat iz predmeta Testiranje softvera (Zadaća 1) - konzolna C# aplikacija za upravljanje bibliotekom.

## Tim i podjela posla
* **Ilhan Lulić, 171-ST** - modul za knjige (`Knjiga.cs`, `KnjigaServis.cs`) i glavni meni (`Program.cs`)
* **Mirza Pupalović, 242-ST** - modul za posudbe (`Posudba.cs`, `PosudbaServis.cs`)
* **Faris Šišić, 268-ST** - modul za korisnike (`Korisnik.cs`, `KorisnikServis.cs`)

## Fajlovi u repozitoriju
* `*.cs` i `PametnaBiblioteka.csproj` - izvorni kod aplikacije
* `Izvjestaj_Inspekcija_Koda.pdf` - izvještaj sa check-listama, tabelom grešaka, metrikama i slikama sa GitHuba
* `Pareto dijagram.png` i `Histogram gresaka.png` - dijagrami grešaka
